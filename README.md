# 🎬 MovieExplorer

A responsive movie and TV show discovery application built with React and the TVMaze API.

## 🚀 Live Demo

Add your Vercel deployment link here.

## 📌 Features

- Browse movies and TV shows
- Search movies and TV shows by title
- Dynamic results using the TVMaze API
- Reusable movie cards
- Movie details modal
- Rating and release information
- Genre and language information
- Loading state
- Error handling
- Responsive design for desktop, tablet, and mobile
- Movie poster fallback for unavailable images

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- CSS
- TVMaze API

## 📡 API

This project uses the TVMaze API.

API endpoints used:

- https://api.tvmaze.com/shows
- https://api.tvmaze.com/search/shows?q={query}

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Go to the project folder:

cd dev-stack-builder

Install dependencies:

npm install

Start the development server:

npm run dev
🏗️ Production Build
npm run build
